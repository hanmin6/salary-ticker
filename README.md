# 今日收入 · 菜单栏工资计数器

由 hanmin6 设计的简约 macOS 菜单栏工资计数器：细椭圆里显示今天已经赚到的金额，点击展开详情。

## 功能

- 菜单栏及详情中的今日收入显示三位小数（如 ¥12.345），每秒重新计算；第三位小数在计薪时快速连续向上滚动，第二位及更高位按真实金额平滑滚动；末位为视觉动效，不影响实际计薪，详情显示真实金额，黑白配色自动适配系统外观。遵循“减少动态效果”，金额不变化时停止动画。
- 点击展开今日收入、工作进度、上下班倒计时和薪资详情。
- 支持币种、月薪、上下班时间、工作日、每月计薪天数设置。
- 可启用午休、设置起止时间，并选择午休是否计薪。午休中显示返回工作倒计时。
- 支持跨午夜班次；下班后停止增长，休息日显示零。
- 支持开机启动，初始关闭，可在详情的“更多”中开启。
- 设置仅存本机，无账号、无联网、无遥测，不占 Dock。

## 百万年薪体验

在详情中点击金色“一键体验年薪百万”，临时按当前币种的年薪 1,000,000（每月 1,000,000 ÷ 12）重新展示收入。工作时间、工作日、午休和计薪天数沿用真实设置。菜单栏同步显示体验金额，详情明确标注体验模式。点击“退出百万年薪体验”立即恢复真实工资。模式不写入工资设置，重启应用后自动退出。按钮光泽遵循系统减少动态效果。

## 构建与运行

适用于 **Apple 芯片 Mac，macOS 14 或更新版本**。需要 Apple Command Line Tools 中的 Swift 编译器，无需完整 Xcode、开发者会员或第三方依赖。

```sh
./test.sh
./build.sh
```

构建产物：

- `build/今日收入.app`
- `build/今日收入-mac-arm64.zip`

将应用复制到“应用程序”后打开，从顶部菜单栏点击金额查看详情。首次启动会打开工资与作息设置。

构建脚本使用本机临时签名，未做 Developer ID 签名或 Apple 公证，适合自行构建使用。构建在临时目录完成，以避免文件提供程序附加 Finder 元数据干扰签名。

## 计薪规则

```text
日薪 = 月薪 ÷ 每月计薪天数
全天计薪时长 = 工作时段 − 不计薪的午休时长
已计薪时长 = 已过的工作时间 − 已经过的不计薪午休时间
今日收入 = 日薪 × 已计薪时长 ÷ 全天计薪时长
```

默认月薪 5000、09:00–18:00、周一至周五、21.75 个计薪日，均为可修改的演示值。币种只改变单位，不换汇。午休默认关闭，旧配置升级后保持原计薪方式。启用后可选计薪或不计薪；不计薪时收入与计薪进度暂停、时薪按有效工作时长折算，全天日薪不变。午休必须在班次内且不能占满班次，支持跨午夜。暂不自动识别节假日。跨午夜班次归上班当天；设置改变后按新规则重新估算当天金额。这里的金额是估算，不代表实际发薪或到账。

## 数据与卸载

设置保存在本机 UserDefaults，应用 ID 为 `local.deskincome.card`。不上传工资，不读取银行或考勤数据。

卸载前如开启过开机启动，请从详情“更多”关闭，再退出并将应用移至废纸篓。
